# Ecommerce Tala

Aplicacion web que conecta los comercios locales de Tala, Jalisco con sus clientes. Permite reservar mesa o fecha especial, y pedir a domicilio o en sucursal, ante la falta de servicios como UberEats o DidiFood en la localidad.

## Problematica

En Tala, Jalisco hay necesidades sin cubrir por la falta de servicios de reparto y reservacion como UberEats o DidiFood, entre otros. Por eso, las personas dependen de medios tradicionales para acceder a estas comodidades.

## Solucion

Desarrollar una app web asociada con varios negocios locales, donde el usuario pueda realizar distintas acciones: reservar alguna mesa o fecha en especial, y solicitar pedidos para entrega a domicilio o en la misma sucursal. Esto da mayor comodidad y fiabilidad al usuario para realizar mas actividades sin complicarse en lo cotidiano.

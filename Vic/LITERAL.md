Proyecto de App Web

Problemática
Dentro de la localidad de Tala, Jalisco se necesita resolver necesidades a falta de servicios como lo son UberEats, DidiFood, entre otras. Por lo que, las personas usan los medios tradicionales para hacer uso de estas comodidades.


Solución
Se planea desarrollar una app web, que tenga asociación con varios negocios, dentro de los cuales, el usuario podrá realizar diferentes acciones, por ejemplo: reservar alguna mesa o fecha en especial, solicitar pedidos  para entrega a domicilio o en la misma sucursal. Esto, le da mayor comodidad y fiabilidad al usuario para poder realizar mayores actividades sin complicarse de manera cotidiana.



Elementos del Software
- [ ] Registro del usuario
- [ ] Navegación entre pantallas y comercios
- [ ] Pasarelas de Pago
- [ ] Información del cliente
- [ ] Información del negocio -> Subdividir en perfil y disponibilidad
- [ ] Información del repartidor
- [ ] Geolocalización
- [ ] Dashboard independiente para cada negocio/sucursal
- [ ] Apartado de reseñas
